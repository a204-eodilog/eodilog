# Quickstart: 여행 만들기와 여행 상세 확인

## 준비

1. 백엔드 로컬 실행: `EodiLog`에서 `.\dev-up` (Docker Desktop 필요)
2. `frontend/.env`의 `EXPO_PUBLIC_API_BASE_URL`을 폰에서 닿는 주소로 (예: PC의 내부 IP `http://192.168.x.x:8080`)
3. 안드로이드 개발 빌드 설치 후 `npx expo start`
4. 카카오 로그인 후 닉네임까지 마친 계정

## 자동 검사

```bash
npm run typecheck
npm run lint
npm test
```

기대: 모두 통과. `npm test`에 `seoul-date`, `trip-rules`, `idempotency`, `errors` 테스트가 있다.

## 측정 기록

- 시나리오 4: `POST /trips` 요청 수(앱 로그), 생성된 여행 수
- 목록 50개 스크롤: preview 빌드 + Flashlight 평균 FPS (기준값)
- 시나리오 13: 여행 탭 첫 화면까지 `GET /me/trips` 요청 수

앱 로그는 `npx expo start`를 띄운 터미널에 `[api] → POST /trips key=…`, `[api] ← 201 POST /trips`처럼 찍힌다(개발 모드에서만). 화살표 `→` 줄 수가 보낸 요청 수다.
