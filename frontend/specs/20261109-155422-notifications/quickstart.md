# Quickstart: 인앱 알림 확인

1. `npm test -- src/features/notification` — 규칙·목록·볼 수 없음·팝업 테스트 통과.
2. 테스트 모드 웹(`fe-c-web`)에서 `/dev/notifications` — 6개 상태 버튼이 Figma와 같은 모양.
3. 테스트 모드로 앱 열기 → "새 알림 N개" 팝업 → [닫기] → 다른 탭 갔다 오기·창 다시 보기 → 같은 팝업이 다시 뜨지 않음.
4. 홈 종 → 목록 → 안 읽은 줄 누르기 → 대상 화면, 뒤로 오면 그 줄이 읽음.
5. [모두 읽음] → 파란 점이 사라지고 홈 종 숫자 없음.
6. '나간 여행' 줄 누르기 → 볼 수 없음 → [이 알림 지우기] → 목록에서 빠짐.
