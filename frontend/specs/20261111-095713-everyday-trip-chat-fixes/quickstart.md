# Quickstart: 여행·채팅 일상 문제 고치기

## 자동 확인

```bash
cd frontend
npx jest src/features/chat src/features/invitation src/hooks
npx jest
npx tsc --noEmit
npx expo lint
```

## 테스트 모드에서 눌러 보기

1. 대화방 두 번 열림: 채팅 탭에서 방을 빠르게 두 번 누른다. 뒤로 한 번에 목록이 나와야 한다.
2. 빈 대화방: 메시지가 없는 방을 연 채 콘솔에서 `__devMock.chat.incoming('여행 id', '안녕')`을 세 번 부른다. 세 개가 순서대로 보여야 한다.
3. 여행 메뉴: 여행마다 코스·평가·경비·게시를 누른다. 결과는 [menu-check.md](./menu-check.md)와 같아야 한다.
4. 자동 참여 실패: 이미 동행인 여행의 초대 링크를 연결을 끊은 채 연다. "여행으로 이동하지 못했어요"와 [다시 시도], [홈으로]가 보여야 한다.

## 사용자가 휴대폰에서 확인할 것

- 먼저 고쳐 둔 7가지: 비행기 모드에서 처음 여는 화면의 끊김 안내, 당겨서 새로고침, 끊긴 동안 누른 저장, 초대 뒤 뒤로 가기, 볼 수 없는 여행에서 여행 목록으로, 앱 복귀 때 대화방 목록, 채팅 스크롤
- 이번에 고친 3가지와 여행 메뉴 네 개
