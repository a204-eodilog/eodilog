# 사진 칸 확인 기록

**확인한 날**: 2026-11-11
**환경**: 테스트 모드 웹 미리보기

## 사진이 보이는 칸

| 화면·칸 | 결과 | 확인 방법 |
| --- | --- | --- |
| 여행 사진 목록 (S31) | 사진 10장이 모두 보인다. 다시 열어도 같은 사진이다 | 미리보기에서 봄 |
| 여행 상세·채팅의 동행 얼굴 | 다른 사람 일부가 사진 얼굴, 나머지는 글자 얼굴이다. 나는 글자 얼굴이다 | 미리보기에서 봄 |
| 피드 상세의 표지·사진·장소 사진 (S07) | 시험 사진 주소라 샘플 사진으로 바뀐다 | 주소 변환 테스트로 확인. 화면은 눌러 보지 않음 |
| 타임라인 요약 표지 (S42), 내 여행 기록 사진 (S38) | 여행 사진의 자산 id를 쓰므로 여행 사진과 같이 보인다 | 코드로 확인. 화면은 눌러 보지 않음 |

## 이번에 사진을 넣지 못한 칸

| 화면·칸 | 까닭 | 넘긴 곳 |
| --- | --- | --- |
| 홈의 여행지 카드·피드 카드 (S05·S06) | `home-rules.ts`가 사진 주소를 늘 비워 둔다. 서버 응답에는 표지 사진 id만 있고 주소가 없다 | 홈 담당 |
| 요즘 뜨는 여행지·여행지 정보 (N2·N3) | `destination-rules.ts`가 사진을 늘 비워 둔다. 서버 응답에 사진 칸이 없다 | 여행지 담당 |
| 장소 정보 시트 | `place/info.ts`가 사진 주소를 늘 비워 둔다. 서버 응답에 사진 칸이 없다 | 장소 담당 |
| 추천·그룹 즐겨찾기 장소 줄 | 사진 칸이 없는 디자인이다 | 해당 없음 |

화면 규칙 코드가 주소를 채우게 되면 시험 사진 주소(`/assets/sample-…/download`)만 넣어도 샘플 사진이 보인다.

## 사진을 받는 중이거나 못 받았을 때

| 칸 | 보이는 것 | 조치 |
| --- | --- | --- |
| 얼굴 사진 (공통 Avatar) | 받는 동안과 못 받았을 때 이름 첫 글자 얼굴이 보인다. 고치기 전에는 빈 동그라미였다 | 고침 |
| 여행 사진 칸, 피드 사진 칸 | 회색 칸만 보인다. 빈 그림 표시는 주소가 아예 없을 때만 나온다 | 다른 담당 화면이라 고치지 않음. 넘김 |

미리보기에서는 샘플 사진이 처음 받을 때 몇 초 걸렸다. 그동안 여행 사진 칸은 회색, 얼굴은 글자로 보였다.

## 사용자가 휴대폰에서 확인할 것

- 인터넷이 될 때 여행 사진과 얼굴 사진이 보이는지
- 비행기 모드에서 같은 화면을 열어 위 표와 같은지
