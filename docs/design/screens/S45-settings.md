# S45 설정 화면 · Figma 수정 전달문

## 구현 범위

화면 및 로컬 상태만 구현했다. 서버 저장, 탈퇴 호출은 없다. 프로필 사진 선택과 취향 편집은 /dev/settings에서 검토할 수 있다. 일반 /settings의 프로필·취향은 기존 화면에 연결되므로 저장 후 복귀 흐름은 후속 작업이다. PRD/API/ERD는 변경하지 않았다.

- 미리보기: /dev/settings
- 상세 바로 보기: /dev/settings?screen=ai, ?screen=profile, ?screen=preferences
- 개발 도구: 실패 흉내 내기, 초기화. 실제 디자인에는 포함하지 않는다.
- 설정 실패: 이전 값 복원과 재시도 토스트. 새로고침하면 샘플 값으로 초기화된다.
- 취향 입력: 기존 온보딩 규칙을 재사용한다. 항목당 20자, 최대 20개, 공백 정리·중복 방지. 특수문자 일괄 금지는 없다. 이 한도는 서버 확정 규칙이 아니라 기존 프론트 임시 기준이다.

## Claude에게 전달할 Figma 수정 프롬프트

어디로그 Figma의 S45를 아래 구현안에 맞춰 수정해 줘. 코드는 수정하지 말고 Figma만 작업해 줘.

파일: https://www.figma.com/design/GDzsmFpkkSRSUzQTWpBtVc/eodilog
기본 프레임: 201:24201 / 실패 프레임: 201:32262
기존 어디로그(파랑) 디자인 시스템의 컴포넌트·색·글꼴·간격을 재사용하고, 실제 앱 화면도 함께 확인해 줘. 로컬 미리보기는 http://localhost:8082/dev/settings 이다. 접근 불가하면 캡처를 요청해 줘.

1. 설정 첫 화면
- 제목: 프로필과 설정.
- 프로필 요약: 아바타·닉네임·핸들, 링크 복사.
- 내 정보: 프로필 수정 >, 여행 취향 >. 취향 오른쪽은 'N개 선택', 0개면 '선택 안 함'. 바다·맛집처럼 일부 단어를 나열하지 않는다.
- AI 기능 설정은 요약 행으로 두고 전체 화면 상세로 이동한다.
- 알림은 첫 화면에 그대로 둔다: 팔로우 요청, 투표·코스 소식, 여행 소식 스위치 3개.
- 계정 공개 스위치와 공개 범위 설명, 로그인 계정, 로그아웃, 탈퇴를 둔다.
- 스위치는 켜짐=브랜드 파랑+흰색 손잡이, 꺼짐=회색+흰색 손잡이. 초록색은 쓰지 않는다.

2. AI 기능 설정 상세
- 사진 주제 분류·묶음, 사진으로 방문 장소 찾기, 링크·캡처 장소 찾기, 준비물 제안, 날씨 대안 5개.
- 자동/확인 후/끄기는 항목 내부 버튼 묶음. 별도 선택 시트를 만들지 않는다.
- 방문 장소 찾기는 현재 결정대로 자동을 비활성화하고 미지원 설명을 유지한다. 임의로 숨기거나 켜지 않는다.
- 날씨 대안은 제안만/끄기.
- 뒤로 가면 설정 첫 화면. 실패 상태는 선택 복원+토스트.

3. 프로필 편집안
- 프로필 만들기가 아니라 프로필 수정.
- 중앙 사진과 카메라 버튼, 사진 변경 문구, 닉네임 입력, 연령대 비공개 표시, 하단 저장 버튼.
- 개발 안내나 서버 미지원 안내를 길게 넣지 말고 실제 미리보기의 간결한 문구와 간격을 따른다.
- 사진 변경은 UI 미리보기에서만 확인한 동작이다. 서버 지원 완료로 문서화하지 않는다. 연령대는 읽기 전용이다.

4. 여행 취향 편집안
- 어떤 여행을 좋아하세요? → 직접 입력+추가 → 내 취향(N/20) → 이런 취향은 어때요? → 하단 저장 순서.
- 내 취향은 X로 제거, 아래 후보는 +로 추가한다. 온보딩과 동일한 칩 체계를 쓴다.
- 직접 입력은 항목당 20자, 최대 20개. 빈 입력·중복 오류는 필요할 때만 보여준다.
- 추천 후보는 고정 선택 후보이며 새 AI 추천 기능이 아니다.

5. 연결과 결과
- 설정 → AI 상세 → 뒤로, 프로필/취향 편집 → 저장/뒤로, 탈퇴 → 기존 S50 확인창을 연결한다.
- 프로필·취향의 편집안은 개발 미리보기 기준이며 실제 라우트의 복귀 연결은 후속 개발임을 별도 메모한다.
- 상태 미리보기 버튼 등 개발 전용 UI는 디자인에 넣지 않는다.
- PRD나 API 의미, 자동화 기본값은 바꾸지 않는다.
- 수정한 프레임 링크와 변경 내역을 알려 줘. 기존 다른 화면은 임의로 변경하지 않는다.
