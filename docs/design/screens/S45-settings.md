# S45 프로필·취향·설정

담당 A · 완성도 · 요구사항 WD-FR-01, 08 · 여는 곳 S37

화면 규칙은 [화면 목록](../../flow/screen-list.md) S45 줄, 흐름은 [사용자 흐름](../../flow/user-flow.md) "S45 화면 구현 보충". 구현은 `frontend/src/features/settings`.

## 구현 범위

- **실제 화면 `/settings`**: 내 정보 `GET /me`, 취향 개수 `GET /me/preferences`(없으면 0개), AI·알림 `GET·PATCH /me/settings`. 바꾸면 화면에 먼저 반영하고 바뀐 필드만 `expectedVersion`과 함께 보낸다. 실패하면 이전 값으로 돌리고 [다시 시도] 토스트, 409 `VERSION_CONFLICT`면 되돌리지 않고 다시 불러온다.
- 계정 공개 스위치는 바꾸는 API가 없어 누르면 "공개 설정은 곧 바꿀 수 있어요" 토스트만 띄운다. 탈퇴는 S50 문구 확인창에서 [탈퇴하기]를 누르면 `DELETE /me`(202)를 보내고, 성공하면 기기의 자료·토큰을 지우고 첫 화면으로 간다("탈퇴했어요" 토스트). 실패하면 로그인 상태 그대로 두고 확인창에 "탈퇴하지 못했어요"를 보여 다시 누를 수 있게 한다. 401은 이미 탈퇴된 것으로 보고 성공과 같이 처리한다(응답이 끊긴 뒤 다시 누른 경우).
- 핸들은 명세에 없어 실제 화면에서는 보여 주지 않는다. 로그인 계정은 카카오만 있어 "카카오로 로그인" 고정.
- 프로필·취향은 기존 `/profile`, `/preferences?from=settings`로 간다. 저장 뒤 S45로 돌아오는 연결은 후속.
- **미리보기 `/dev/settings`**: 예시 값(`sample-data.ts`)으로만 동작하고 서버에 저장하지 않는다. 상세 바로 보기 `?screen=ai`, `?screen=profile`, `?screen=preferences`. 실패 흉내 내기·초기화 버튼과 안내 문구는 개발용이라 디자인에 넣지 않는다. 프로필 사진 선택·취향 편집 편집안은 여기서만 볼 수 있다.
- 개발 테스트 모드(`devMock`)의 가짜 서버도 `GET·PATCH /me/settings`를 흉내 낸다(버전 검사 포함).
- 취향 입력 규칙은 온보딩과 같다. 항목당 20자, 최대 20개, 공백 정리·중복 방지. 이 한도는 서버 확정 규칙이 아니라 기존 프론트 임시 기준이다. PRD/API/ERD는 바꾸지 않았다.

## 설정 첫 화면

1. **상단 바** — [뒤로], 제목 "프로필과 설정"
2. **프로필 요약** — 아바타, 닉네임, 핸들, 오른쪽 [링크 복사]
3. **내 정보** — 프로필 수정 >, 여행 취향 > 오른쪽 "N개 선택"(0개면 "선택 안 함"). 키워드를 나열하지 않는다
4. **앱 설정** — AI 기능 설정 > 한 줄. 누르면 AI 기능 설정 상세
5. **알림** — 팔로우 요청, 투표·코스 소식, 여행 소식(설명 "동행 참여·여행 정보 변경") 스위치 3개
6. **계정** — 계정 공개 스위치 + 설명("누구나 내 공개 기록을 볼 수 있어요" / 비공개면 "승인한 팔로워만 내 기록을 볼 수 있어요"), 로그인 계정(값 "카카오로 로그인"), 로그아웃, 탈퇴(→S50 확인창)

스위치는 켜짐 브랜드 파랑, 꺼짐 회색, 손잡이는 흰색이다.

## AI 기능 설정

- 상단 바 [뒤로](→ 설정 첫 화면), 제목 "AI 기능 설정". 안내 "AI가 도와줄 일과 실행 방식을 선택해 주세요."
- 다섯 기능, 항목 안 버튼 묶음으로 바로 고른다(따로 시트를 열지 않음)

| 기능                      | 선택지                        | 설명                                                             |
| ------------------------- | ----------------------------- | ---------------------------------------------------------------- |
| 사진 주제 분류와 묶음     | 자동 / 확인 후 / 끄기         | 사진을 주제별로 나눠요                                           |
| 사진으로 방문 장소 찾기   | 자동(비활성) / 확인 후 / 끄기 | 방문 기록은 직접 확인해야 해요. 자동 실행은 아직 지원하지 않아요 |
| 링크와 캡처에서 장소 찾기 | 자동 / 확인 후 / 끄기         | 링크·캡처 속 장소를 찾아요                                       |
| 준비물 제안               | 자동 / 확인 후 / 끄기         | 날씨·일정 기준 준비물                                            |
| 날씨 대안                 | 제안만 / 끄기                 | 코스는 제안만 해요                                               |

값과 기본값은 `UserSettings`(AI 네 개 CONFIRM, 날씨 SUGGEST_ONLY, 알림 셋 true)를 그대로 따른다.

## 프로필 수정 (편집안)

가운데 사진 + 카메라 버튼, "사진 변경", 닉네임 입력(1~50자, 아래 글자 수), 연령대는 값만 보여 주는 읽기 전용 + "비공개" 꼬리표, 아래 [저장]. 사진 변경과 연령대 수정은 서버에 없다(`PATCH /me`는 닉네임만).

## 여행 취향 (편집안)

"어떤 여행을 좋아하세요?" → 직접 입력 + [추가] → 내 취향(N/20, X로 빼기) → 이런 취향은 어때요?(+로 넣기, 고정 후보) → 아래 [저장]. 칩은 S03과 같다.
