# S50 삭제·나가기·탈퇴 확인

담당 B(틀) · 완성도 · 요구사항 WD-FR-32, Q-11 · 여는 곳 S19(C), S32, S35, S38, S39(A), S45(A)

화면 규칙은 [화면 목록](../../flow/screen-list.md) S50 줄: 영향 안내, 여행 나가기는 내 사진·채팅 삭제 체크·경비 유지 안내, 방장이면 받을 사람 안내, 혼자 남으면 여행 삭제 안내, 진행/취소.

**공통 확인 시트**: B가 틀을 만들고, 여행 나가기 문구는 C, 탈퇴 문구는 A가 채운다. 공통 `BottomSheet`의 `title` `description` `footer`로 만들 수 있다(`/dev/ui` 하단 시트 예시가 이 모양).

API: 여행 나가기 `POST /trips/{tripId}/leave`(혼자 남은 사람은 202 + `tripDeleted:true`), 여행 삭제 `DELETE /trips/{tripId}`. 사진·메시지 지우기 옵션은 서버의 정리 작업이 생기기 전까지 `true`를 보내면 400이라, 그 전까지는 기능 명세(`frontend/specs` trip-members-leave 가정)대로 체크를 끈 채로 보여 주고 줄 설명에 "지우기는 곧 지원돼요"를 붙이며 항상 `false`를 보낸다(2026-11-04). 정리 작업이 생기면 체크를 연다.

## 여행 나가기

시트 안쪽 좌우 20·아래 34, 손잡이 36x4 `colors.gray[300]`.

1. **제목 줄** — "겨울 여행에서 나갈까요?" `typography.title1`, 간격 2, 정보 아이콘 16 + "나가면 이렇게 바뀌어요" `typography.caption` `colors.text.icon`
2. **바뀌는 것 목록** — 위 16, 줄 사이 14. 줄(높이 48, 간격 14): 회색 동그라미 36(`colors.surface.default`) 안 아이콘 18 · 이름 `typography.bodyBold` + 설명 `typography.caption` `colors.text.icon`
   - 지도: "내 지도에서 이 여행이 빠져요"
   - 사진: "올린 사진 12장, 지울지 골라요" — 줄 오른쪽 끝에 동그란 체크 24. 기본은 빈 상태(흰 바탕, 테두리 `colors.gray[300]` 1.5), 고르면 `colors.brand.primary` 바탕에 흰 체크(방장일 때 상태 그림). 고르면 설명이 "사진 12장도 지워요 · 피드는 남아요"로 바뀐다
   - 채팅: "보낸 메시지, 지울지 골라요" — 같은 체크. 고르면 "보낸 메시지도 지워요"
   - 줄 안 글자 칸이 남은 폭을 채우고 체크는 오른쪽 끝에 붙는다
   - 정산: "경비 기록은 남아요"
3. **버튼 줄** — 위 20, 오른쪽 정렬, 간격 10. 글자 버튼 "취소"(`typography.bodyMedium` `colors.text.icon`, 좌우 16), 빨간 알약 48 "나가기"(나가기 아이콘 20, `Button variant="danger"`)

## 공통 부품과 맞지 않는 점

- 공통 체크박스는 아직 없다(2차 부품 목록). 이 화면의 동그란 체크를 첫 쓰임으로 삼아 만들면 된다. 피그마 기본·처리 실패 상태에 빈 체크를 2026-11-03에 추가했다.
- 설명 안 글자 링크("다른 사람에게 넘기기")를 넣는 자리가 공통 `BottomSheet`의 `description`에는 없다. `children`으로 넣으면 된다.

## 예시 데이터

방장 넘김 대상은 피그마에서 민준(가장 먼저 참여한 동행)으로 바꿔 적었다.

## 그 밖의 상태

모두 "여행 나가기"와 같은 시트 틀(좌우 20·아래 34, 손잡이, 제목 `typography.title1`, 설명 `typography.caption` `colors.text.icon`, 버튼 줄 위 20·오른쪽 정렬·간격 10). 공통 `ConfirmSheet`로 만든다.

- **여행 나가기 · 방장일 때** — 설명 "나가면 민준님이 방장이 돼요 · 다른 사람에게 넘기기"(뒤쪽은 글자 링크 → S19 방장 넘기기). 사진 줄 "사진 12장도 지워요 · 피드는 남아요", 채팅 줄 "보낸 메시지도 지워요"에 각각 체크(고른 상태: `colors.brand.primary` 바탕 + 흰 체크). 빨간 버튼 [나가기 아이콘 + "나가기"]. 피그마는 글자 크기가 12/18·16/24로 그려져 있으나 토큰으로 맞춘다
- **여행 나가기 · 혼자 남았을 때** — 제목 "혼자 남아서 나가면 여행이 삭제돼요", 설명 "겨울 여행의 기록이 모두 지워져요". 줄 설명: 지도 "내 지도에서 이 여행이 빠져요", 사진 "여행 사진이 모두 지워져요", 채팅 "그룹 채팅방이 사라져요", 정산 "경비 기록도 함께 지워져요". 체크 없음. 빨간 버튼 "나가고 여행 삭제"
- **처리 실패** — 기본 시트 그대로 두고 목록 아래(위 16) [README 상태 공통 모양](README.md#상태-공통-모양)의 **오류 띠**: "나가지 못했어요", "다시 시도해 주세요". 빨간 버튼이 [새로고침 + "다시 시도"]
- **사진 삭제** — 짧은 시트(높이 200): "사진 2장을 지울까요?" `typography.title1`, 위 8 "휴대폰 원본은 그대로예요" `typography.body` `colors.text.icon`, 위 24 버튼 줄 [취소] [휴지통 + "지우기"]
- **탈퇴** — 짧은 시트(높이 226): "어디로그를 탈퇴할까요?", "내 기록이 모두 지워져요.⏎함께 만든 여행은 동행에게 남아요" `typography.body` `colors.text.icon`, 버튼 줄 [취소] ["탈퇴하기"](아이콘 없음, 좌우 24)
- **지출 삭제**(S35, 피그마 없음) — 사진 삭제와 같은 짧은 시트: "이 지출을 삭제할까요?", "{지출 이름} {금액}원이 목록과 합계에서 빠져요.⏎정산을 했다면 다시 계산해야 해요", 버튼 줄 [취소] [휴지통 + "삭제"](`Button variant="danger"`). 처리 실패는 "지출을 삭제하지 못했어요" 오류 띠 + [다시 시도]
- **평가 삭제**(S34, 피그마 없음) — 같은 짧은 시트: "내 평가를 삭제할까요?", "{장소 이름}에 남긴 점수와 글이 지워져요.⏎다시 남길 수 있어요", 버튼 줄 [취소] [휴지통 + "삭제"]. 처리 실패는 "평가를 삭제하지 못했어요" 오류 띠 + [다시 시도]

## 버튼과 이동

[사용자 흐름](../../flow/user-flow.md) 기준. 누르는 것마다 어디로 가는지와 어떤 API를 부르는지.

| 누르는 것 | 어디서 | 동작·이동 |
| --- | --- | --- |
| 어두운 막, 아래로 끌기, [취소] | 모든 상태 | 닫고 원래 화면. 처리 중에는 닫히지 않게 할 예정(공통 BottomSheet 잠금 옵션) |
| 사진·채팅 체크 | 여행 나가기 | 지울지 고르기(`deleteOwnPhotos`·`deleteOwnMessages`). 서버 정리 작업이 생기기 전까지는 체크를 끈 채로 보여 주고 "지우기는 곧 지원돼요" 안내, `false`로 보냄 |
| [다른 사람에게 넘기기] | 여행 나가기 · 방장일 때 | S19 방장 넘기기 대상 선택(C) |
| [나가기] | 여행 나가기 | `POST /trips/{tripId}/leave`(본문 `expectedVersion` 포함) → 성공하면 S15 여행 목록(C). 실패하면 처리 실패 상태 |
| [나가고 여행 삭제] | 혼자 남았을 때 | 같은 API, 202 + tripDeleted → S15 |
| [다시 시도] | 처리 실패 | 같은 요청 다시 |
| [지우기] | 사진 삭제 | `DELETE` 사진 → S31로, 토스트 "사진 N장을 지웠어요" |
| [탈퇴하기] | 탈퇴 | `DELETE /me` → 로그아웃 후 S01 로그인 |
| [삭제] | 지출 삭제 | `DELETE /trips/{tripId}/expenses/{expenseId}?expectedVersion=…` → S35로, 목록·합계 갱신 |
| [삭제] | 평가 삭제 | `DELETE /trips/{tripId}/visits/{visitId}/review` → S34 작성 상태로 |
