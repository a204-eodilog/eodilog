# S05 홈 친구 여행 지도

담당 A · 핵심 · 요구사항 WD-FR-24, 25, 10, 34 · 홈 탭 첫 화면

화면 규칙은 [화면 목록](../../flow/screen-list.md) S05 줄과 [화면 공통 기준](../design-decisions.md) "S05 홈". 구현은 `frontend/src/features/home`, 지도는 공통 부품 `KoreaMap`(`frontend/src/components/ui/korea-map.tsx`).

**지도는 네이버 지도가 아니라 시도·시군구 경계를 SVG로 그린 "물든 지도"다.** 지도 키 없이 웹 미리보기에서도 보인다. 같은 부품을 S37 마이페이지·S40·S07 경로·S42 요약 카드가 쓴다.

## 기본

1. **위** — 로고(채운 핀 아이콘 + "어디로그" `typography.title2`), 오른쪽 알림 종(안 읽은 수 배지, `GET /me/notification-summary`)
2. **지도** — 바다 `colors.map.sea`, 땅 흰색, 시군구 선 `colors.line.default`, 시도 선 `colors.line.strong`. 처음에는 본토 + 제주가 위 알약과 아래 시트를 피한 자리에 꽉 차게(울릉도·독도는 옮기면 보임). 다녀간 친구 수로 시군구를 4단계 파랑(`colors.map.step1~4`: 1명 / 2명 / 3명 / 4명 이상)
3. **지역 알약 핀** — 흰 알약(지역 짧은 이름 `captionBold` + 사람 아이콘 + 친구 수 `colors.brand.primary`) 아래 검은 점(흰 테두리). 누르면 S06 같은 지역 여행 목록
4. **"요즘 뜨는 여행지"** — 위 왼쪽 흰 알약 44 → S09
5. **아래 시트** — "♡ 좋아요한 여행과 비슷해요". 접으면 가로 카드(사진 56 + 제목 + 사람·박수 또는 장소), 펼치면 세로 목록(사진 64 + 화살표). 누르면 여행은 S07, 장소는 N7. N7(이어서 S08 저장 시트)이 열려 있는 동안은 S06처럼 추천 시트가 내려가 시트가 겹치지 않고, 닫으면 다시 올라온다
6. 오른쪽 아래 **"지도 출처: 통계청 SGIS"** — 지우지 않는다

손가락: 두 손가락 확대·축소(최대 5배), 한 손가락 이동, 두 번 누르면 2배. 핀은 확대해도 크기가 같다. 처음 화면보다 작게 줄이거나 한국 밖으로 옮길 수 없다.

### 확대 5단계 (WD-FR-24)

단계 안에서는 핀 모양과 선 굵기가 그대로이고, 단계가 바뀔 때만 다시 그린다(확대 중 선이 생겼다 사라지는 깜빡임 방지). 값은 `KoreaMap`의 `MAP_STAGES`.

| 단계          | 배율    | 시군구 선 | 핀                                                                                    |
| ------------- | ------- | --------- | ------------------------------------------------------------------------------------- |
| 1 전국        | 1 ~     | 숨김      | 같은 시도에 2곳 이상이면 시도로 묶음 "강원 8곳 · 친구 4". 핀은 다녀간 시군들의 가운데 |
| 2 권역        | 1.6 ~   | 보임      | 시군 이름표. 화면에서 겹치는 것끼리 묶음 "평창·강릉", "평창·강릉 외 2곳"              |
| 3 시군        | 2.4 ~   | 보임      | 시군 이름표(겹치면 묶음)                                                              |
| 4 가까이      | 3.2 ~   | 보임      | 시군 이름표(겹치면 묶음)                                                              |
| 5 가장 가까이 | 4.2 ~ 5 | 보임      | 시군 이름표(겹치면 묶음)                                                              |

- 묶음 대표는 친구가 가장 많은 지역, 친구 수는 같은 친구를 한 번만 센다
- 확대할수록 묶음은 풀리기만 한다
- 지도에는 사진 카드를 놓지 않는다(가까운 지역이 많으면 카드가 겹쳐 읽기 어려움). 사진은 S06 시트에서 본다
- 묶음 이름은 친구가 많은 지역부터 두 곳까지 적는다. 두 곳은 "평창·강릉", 세 곳부터 "평창·강릉 외 1곳"
- 묶음 핀을 누르면 그 자리로 한 단계 확대. **4·5단계에서는 확대하지 않고 아래 S06 시트를 연다**(묶인 지역 전체)

## S06 같은 지역 여행 목록 (홈 위 시트)

S06은 따로 화면을 두지 않고 홈 지도 위 시트로 보인다(`components/region-trips-sheet.tsx`).

- 여는 법: 지역 핀(어느 단계든) → 그 지역만 / 4·5단계의 묶음 핀 → 묶인 지역 전체
- 추천 시트 대신 열리고, 닫으면(X·아래로 끌기·뒤로 가기) 추천 시트로 돌아간다. 처음 60%, 위로 끌면 82%
- 머리: 한 지역이면 "강릉 친구 여행", 여럿이면 "이 근처 친구들의 여행" + "평창 · 강릉 · 동해" + 필터 칩(전체 / 지역별)
- 카드: 표지(160, 사진 없으면 연한 파랑 + 그림 아이콘) + 제목 + "지역 · 01.17 – 01.18 · 1박 2일". 누르면 S07
- 불러오기 실패: "강릉 여행을 불러오지 못했어요 / 지도는 그대로 볼 수 있어요" + [다시 시도](여러 지역이면 지역 이름 없이)
- 값: 지역마다 `GET /home/regions/{regionId}/feeds`(FeedCard[]), 최근 게시 먼저(`home-rules.toRegionTripCards`). 지역 ID는 `/home/map` 마커의 `region.id`

## 모션 (Figma S05 기본 · 3.5초 타임라인)

화면에 들어올 때 한 번만 재생한다(Figma는 미리보기라 반복). 기기의 '동작 줄이기'가 켜져 있으면 바로 최종 모습. 값은 `KoreaMap`의 `MAP_MOTION`.

1. **물들기** — 적게 다녀간 지역부터 차례로(Figma: 여수 → … → 강릉). 0.2초부터 0.13초 간격, 한 겹은 0.5초 동안 서서히. 많이 다녀간 곳은 옅은 파랑 위에 진한 겹이 0.35초씩 뒤에 더 물든다(친구 수 단계만큼 1~4겹)
2. **핀 등장** — 물들기가 끝나면(0.2초 + 지역 수 × 0.13초 + 0.18초) 같은 순서로 0.12초 간격, 10px 아래에서 0.35초 동안 올라오며 나타남
3. **퍼지는 원** — 가장 많이 다녀간 지역 점에서 1.6초 동안 0.6배 → 2.6배로 퍼지며 사라지고, 3.5초마다 반복

## API (2026-11-05 기준)

| API                                 | 백엔드   | 쓰는 곳                                                              |
| ----------------------------------- | -------- | -------------------------------------------------------------------- |
| `GET /me/trips?limit=1`             | 있음     | 여행이 있는지(첫 방문)                                               |
| `GET /home/map?bbox=`               | **없음** | 지역 색칠·핀. 없어서 실제 화면은 지금 '지도 로드 실패'               |
| `GET /me/following?limit=1`         | 없음     | 친구 없음 판단. 실패하면 모름으로 두고 '공개된 기록 없음'으로 보인다 |
| `GET /me/discovery-recommendations` | 없음     | 추천 시트. 실패하면 빈 시트 안내                                     |
| `GET /me/notification-summary`      | 있음     | 알림 배지                                                            |

서버 응답은 `home-rules.toRegionMarks` 한 곳에서만 화면 값(`RegionMark`)으로 바꾼다. 응답 모양이 바뀌면 이 함수만 고친다. 개발 테스트 모드(`api/dev-mock.ts`)도 위 API를 흉내 낸다.

## 백엔드에 필요한 것

1. `/home/map` 마커는 **시군구 단위**(`regionGrouping`)로 준다. 시도로는 화면에서 합칠 수 있다
2. `bbox`는 지도 SDK 기준이라, SVG 지도는 처음부터 전국을 본다. 없어도 되게(선택) 해 주면 좋다. 지금은 전국 범위를 보낸다
3. 확대 사진 핀에 필요한 **지역별 대표 표지 사진·여행 이름**과 **다녀간 친구 이름**이 `MapResult`에 없다. 마커에 넣어 주면 지역마다 따로 부르지 않아도 된다. 지금은 사진 자리는 아이콘, 얼굴 대신 친구 수
4. 추천·S06의 `FeedCard`에 표지 사진 주소가 없어(`coverPhotoId`만) 사진 자리는 아이콘. 동행 이름도 없어 S06 카드에 "누구와"를 못 보인다
5. '공개된 기록 없음'의 친구 얼굴 위치는 서버가 주지 않아 미리보기에서만 보인다
