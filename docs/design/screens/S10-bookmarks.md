## 목록 보기

1. **상단 바** — 높이 56, 좌우 여백 20/16. 왼쪽 큰 제목 "저장" `typography.title1`(뒤로 없음, 탭 첫 화면). 오른쪽 **보기 방식 전환**: 회색 알약(`colors.surface.default`, 안쪽 여백 4, 칸 간격 6) 안에 동그라미 버튼 36 두 개. 고른 쪽은 흰 바탕, 아이콘 20(목록 / 지도)
2. **즐겨찾기 종류** — 상단 바 아래, 좌우 20, 위 4·아래 12, 칸 간격 10. 알약 버튼 52x36 두 개, 아이콘 20
   - 개인(고른 상태): 배경 `colors.brand.primaryLight`
   - 그룹: 배경 `colors.surface.default`
3. **목록 머리** — 위 여백 16. 왼쪽 "5곳" `typography.captionMedium` `colors.text.icon`, 오른쪽 "최근 저장한 순" `typography.caption` `colors.text.sub`
4. **장소 카드 2열** — 머리와 간격 24, 두 열 간격 16, 열 안 카드 간격 22. 카드 높이가 사진마다 다른 엇갈린 배치
   - 사진: 가로 꽉(167), 세로 160~220, 둥글기 `radius.lg`(16). 왼쪽 위에 **출처 배지**: 배경 `colors.text.default`, 둥글기 10, 안쪽 여백 3/8, 글자 11/17 보통(Medium) 흰색 — "SNS 게시물", "블로그", "캡처 3장", "민준의 여행"
   - 사진 아래 간격 10: 장소 이름 15/23 굵게 `colors.text.default`, 간격 2, "부산 수영구 · 카페 바다뷰" 12/18 보통 `colors.text.sub2`
5. **[+] 버튼** — 오른쪽 아래 떠 있는 동그라미 56, `colors.brand.primary`, 더하기 아이콘 28 흰색. 누르면 S11
6. **하단 탭** — 공통 `TabBar`, 저장 탭 선택

## 공통 부품과 맞지 않는 점

- 글자 15/23 굵게, 11/17 보통, 12/18 보통은 토큰에 없다.
- 엇갈린 2열 목록은 공통 부품이 없다. `@shopify/flash-list`의 masonry 배치나 두 열을 직접 나누는 방식 중 고른다.
- 떠 있는 동그라미 버튼(56)과 보기 방식 전환 알약은 공통 부품에 없다.
