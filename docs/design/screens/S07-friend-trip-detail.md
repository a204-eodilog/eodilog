## 기본

1. **표지** — 350×196, 둥글기 16. 표지 사진(`coverPhotoId`, 없으면 첫 사진). 사진이 없으면 연한 파랑 바탕 + 그림 아이콘
2. **제목·좋아요** — 제목 `title1`(23), 오른쪽 회색 알약(하트 + 좋아요 수). 누르면 바로 바뀌고(먼저 화면에 반영), 실패하면 되돌리고 "좋아요를 바꾸지 못했어요" 토스트
3. **한 줄 정보** — 동행 얼굴 3개 + "하늘 외 2명", 달력 + "01.17 – 01.18", 달 + "1박 2일". 모르는 값은 그 칸을 숨긴다
4. **탭** — 사진·경로·장소·경비 칩. 누르면 그 섹션으로 스크롤하고, 손으로 내리면 보이는 섹션에 맞춰 선택이 바뀐다. 내용이 없는 섹션은 탭도 숨긴다
5. **사진** — 앞 3장(110, 둥글기 12). 더 있으면 세 번째 위에 "+N". 누르면 사진 모두 보기(준비 중)
6. **경로** — 앱은 **네이버 지도**(높이 180) 위에 장소 번호 핀을 찍고 같은 날끼리 선으로 잇는다(`components/route-map.tsx`). 모든 장소가 들어오게 처음 범위를 맞추고(최소 약 2km), 화면을 넘기는 중이라 지도는 움직이지 않게 고정한다. 1일차는 진한 파랑 실선, 2일차부터 옅은 파랑 점선, 번호는 일차를 넘어 이어진다. 가까운 장소는 번호끼리 가리지 않게 핀만 둥글게 조금 벌린다(선은 실제 좌표, `spreadMarkers`). 이틀 이상이면 왼쪽 아래에 "● 1일차 ● 2일차" 설명(웹 그림과 같은 모양). 서버가 장소 사이 길(`legs.geometry`)을 아직 주지 않아 곧은 선으로 잇는다. 웹 미리보기에는 네이버 지도가 없어 홈과 같은 통계청 경계 SVG 그림으로 보인다(`route-sketch.tsx`, "지도 출처: 통계청 SGIS")
7. **장소와 이동** — 일차 배지 + 날짜. 장소마다 사진 56(왼쪽 위 번호), 이름 `bodyBold` + 별 평점, 한 줄 평가, 오른쪽 저장 버튼(40 동그라미). 같은 날 다음 장소 사이에 이동 수단 아이콘 + 시간 알약("12분")
8. **경비** — 회색 카드에 "합계"와 금액("18만 원")

## 값 정하는 법 (`feed-rules.toFeedDetail`)

- 장소 순서: `publicItinerary.items`를 일차 → 순서로
- 평점: 그 장소 `publicReviews` 점수 평균(소수 한 자리). 점수는 정수라 4.5는 두 사람 평가의 평균
- 한 줄 평가: 그 장소에서 가장 먼저 쓴 평가. 앞에 쓴 사람 이름을 붙인다("하늘 · 겨울 바다가…"). 동행이 S34에서 남긴 평가가 게시된 것(`publicReviews`)이고 개인 메모가 아니다. 평가가 여러 개면 모두 보기는 N7에서
- 이동: `legs`에서 같은 날 바로 다음 장소로 가는 구간. WALK → 걷기, CAR·TAXI → 차, BUS·TRANSIT·SUBWAY → 버스, 그 밖은 경로 아이콘
- 사진 주소: `PublicPhoto.imageUrl`은 로그인해야 받는 `/assets/...` 경로라 서버 주소를 붙이고 토큰을 같이 보낸다(`lib/asset-image.ts`)

## 연결

| 누르면    | 가는 곳                                          |
| --------- | ------------------------------------------------ |
| 뒤로      | 이전 화면                                        |
| 좋아요    | `PUT /feeds/{feedId}/like`, 다시 누르면 `DELETE` |
| 사진·+N   | 사진 모두 보기(준비 중)                          |
| 장소 줄   | N7 장소 정보 시트(준비 중)                       |
| 저장 버튼 | S08 장소 저장 시트(B 담당)                       |

S05 홈 추천 시트의 여행 카드를 누르면 이 화면으로 온다.

## API (2026-11-05 기준)

- `GET /feeds/{feedId}` → `Feed`. 삭제된 피드는 404
- `PUT /feeds/{feedId}/like` → `{liked, count}`, `DELETE /feeds/{feedId}/like` → 204

## 백엔드에 필요한 것

1. **함께 간 동행이 `Feed`에 없다.** 화면 목록 S07에 "함께 간 동행"이 있다. `members: UserCard[]`(또는 이름·사진만)을 넣어 주면 머리글에 얼굴과 "하늘 외 2명"을 보인다. 지금은 오면 보이고 없으면 숨긴다
2. **경비는 합계만 온다(`PublicExpenseSummary`).** Figma는 "1인" 금액과 숙소·식비·교통·기타 비율 막대를 보인다. 1인 금액(또는 인원 수)과 분류별 합계가 있어야 같게 그릴 수 있다. 지금은 "합계"만
3. **이동 수단 값 목록**(`RouteLeg.transportMode`)이 명세에 없다. 위 표대로 읽고 모르는 값은 경로 아이콘으로 둔다
