# PocketAcoustics 아이디어 문서

> 전문 음향 측정 장비 없이 스마트폰만으로 공간의 음향 환경을 분석할 수 없을까?

## 1. 한 줄 소개

여러 대의 스마트폰을 분산 마이크 네트워크로 연결해 공간의 음향 특성을 분석하고, AI를 활용해 음향 환경 개선을 지원하는 **저비용 공간 음향 분석 플랫폼**.

> **핵심 메시지:** 고가의 전문 장비 없이, 스마트폰 여러 대로 공간의 소리를 측정하고 개선한다.

## 2. 문제 정의

학교 강당, 소규모 공연장, 강의실 등에서는 위치에 따라 소리의 크기와 명료도가 달라지는 문제가 발생한다.

하지만 전문 음향 측정 장비는 가격이 높고 사용에 전문 지식이 필요해 일반 사용자나 소규모 시설 운영자가 활용하기 어렵다.

- 공간의 어느 위치에서 소리가 잘 전달되지 않는지 객관적으로 파악하기 어렵다.
- 스피커 배치나 설정을 변경해도 실제로 개선되었는지 확인하기 어렵다.
- 전문 측정 장비 없이 여러 지점의 음향 특성을 비교하기 어렵다.
- 음향 측정 결과를 비전문가가 이해하고 활용하기 어렵다.

> **문제:** 소규모 시설에서는 전문 장비와 인력의 부족으로 공간의 음향 문제를 데이터에 기반해 분석하고 개선하기 어렵다.

## 3. 타깃 사용자

### 주 사용자: 소규모 공연장·강당 음향 담당자

**페르소나 (가상): 김민준, 24세, 대학교 공연 동아리 음향 담당자**

- 동아리 공연을 위해 학교 강당의 음향을 준비하고 있다.
- 앞쪽 좌석과 뒤쪽 좌석에서 소리가 다르게 들리는 문제를 겪는다.
- 전문 음향 측정 장비가 없어 직접 이동하며 귀로 확인한다.
- 스피커 위치를 조정한 뒤 실제 개선 효과를 객관적으로 확인하고 싶다.

### 보조 사용자: 학교 및 시설 관리자

강의실, 회의실, 소규모 행사장의 음향 상태를 측정하고 관리하려는 사용자.

## 4. 핵심 기능


| #   | 기능         | 설명                                   | 우선순위   |
| --- | ---------- | ------------------------------------ | ------ |
| F1  | 다중 스마트폰 연결 | QR을 통해 스마트폰 4\~8대를 하나의 측정 세션에 연결     | 필수     |
| F2  | 다지점 음향 측정  | 스마트폰 마이크로 여러 위치의 음향 데이터를 동시에 수집하고 보정 | 필수     |
| F3  | 공간 음향 분석   | 위치별 상대 음량, 주파수 응답, 잔향시간 등 분석         | 필수     |
| F4  | 음향 히트맵     | 공간 평면도에 위치별 음향 특성을 색상으로 시각화          | 필수     |
| F5  | 측정 결과 비교   | 스피커 위치·설정 변경 전후의 측정 결과 비교            | 필수     |
| F6  | AI 음향 분석   | 측정 결과를 해석하고 개선이 필요한 구역 및 조정 방안 제안    | AI·차별화 |
| F7  | 측정 품질 검증   | AI로 주변 소음, 마이크 움직임 등 측정 오류 탐지        | AI·차별화 |
| F8  | 음향 분석 리포트  | 공간별 측정 결과와 개선 전후 변화를 보고서로 제공         | 후순위    |


## 5. AI 활용


| AI 기능       | 방법                              | 결과                       |
| ----------- | ------------------------------- | ------------------------ |
| ① 측정 품질 분석  | 음향 특징 분석 및 이상 탐지 모델             | 주변 소음·측정 오류 감지           |
| ② 음향 문제 분석  | 잔향시간·주파수 응답·위치별 음량 데이터를 종합 분석   | 개선이 필요한 구역 탐색            |
| ③ 음향 개선 가이드 | 측정 수치와 음향 시뮬레이션을 기반으로 LLM 설명 생성 | 스피커 위치·각도 등 개선 실험 제안     |
| ④ 자동 보고서    | 측정 전후 데이터 기반 LLM 요약             | 비전문가도 이해할 수 있는 음향 분석 리포트 |


### 핵심 분석 지표

- 상대 음량 편차: 좌석별 소리 크기 차이
- 주파수 응답: 특정 위치에서 강조되거나 약해지는 주파수 대역
- 잔향시간(RT60): 소리가 공간에서 감쇠하는 특성
- 명료도(C50): 초기음과 후기 반사음의 에너지 비율

## 6. 기존 서비스와 차별점


| 기존 방식            | 제공하는 것         | PocketAcoustics               |
| ---------------- | -------------- | ----------------------------- |
| 전문 음향 측정 장비      | 정밀한 음향 분석      | 스마트폰을 활용한 저비용 기초 음향 측정        |
| 일반 소음 측정 앱       | 단일 위치의 소음 수준   | 다중 스마트폰으로 공간별 음향 특성 비교        |
| REW 등 음향 분석 프로그램 | 전문적인 주파수·잔향 분석 | 다지점 측정 자동화, 공간 히트맵, AI 개선 가이드 |


전문 장비의 모든 기능을 대체하는 것이 아니라, 소규모 공간에서 필요한 기초 음향 분석과 개선 효과 검증에 집중한다.

## 7. 사용자 흐름

1. 관리자가 측정할 공간을 등록하고 평면도를 설정한다.
2. 스마트폰 4\~8대를 객석 곳곳에 배치하고 QR로 연결한다.
3. 스피커에서 테스트 신호를 재생하고 각 스마트폰이 동시에 녹음한다.
4. 서버가 수집된 데이터의 시간 정렬과 기기별 보정을 수행한다.
5. 잔향시간, 주파수 응답, 음량 편차 등을 계산하고 히트맵으로 표시한다.
6. AI가 측정 결과를 해석하고 개선 방안을 제안한다.
7. 스피커 위치나 설정을 변경한 뒤 재측정하여 개선 전후를 비교한다.

## 12. MVP 범위

- **필수:** 다중 스마트폰 연결, 동시 음향 측정, 주파수·잔향 분석, 공간 히트맵, 전후 비교
- **AI·차별화:** 측정 품질 검증, 음향 특성 해석, 개선 실험 추천
- **후순위:** 자동 PDF 보고서, 3D 공간 음향 시각화
- **제외:** 전문 계측 장비 수준의 정밀도 보장, 실시간 능동 소음 제거

## 13. 열린 질문 (1주차 검증)

- 스마트폰 4대 이상에서 안정적인 동시 녹음이 가능한가?
- 기기별 마이크 차이를 어느 정도 보정할 수 있는가?
- 스마트폰으로 측정한 잔향시간이 기준 장비 측정값과 어느 정도 일치하는가?
- 실제 강당이나 공연장에서 사용자 테스트를 진행할 수 있는가?

> **PocketAcoustics는 고가의 전문 음향 측정 장비를 완전히 대체하는 서비스가 아니라, 전문 장비에 접근하기 어려운 사용자도 공간의 음향 환경을 데이터 기반으로 분석하고 개선할 수 있도록 돕는 플랫폼이다.**
