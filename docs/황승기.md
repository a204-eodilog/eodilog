# 아이디어 정리

## 1. 생활패턴 교환소

교대근무자, 야간 근무자 등 생활시간이 특이한 사람들이 비슷한 시간대에 가능한 활동을 연결합니다.

### 핵심 기능

- 시간 구간 매칭
- 일정 충돌 계산

## 2. MYSTERY MARKET — AI 블라인드 취향 거래소

> **신선함 1순위**  
> "물건이 뭔지 모르는 상태에서 취향만 보고 구매한다면?"

판매자가 물건을 등록하면 AI가 브랜드와 제품명을 가리고 특징만 설명합니다. 구매자는 사진 없이 취향 설명과 조건을 보고 상품을 선택합니다.

### 사용자 흐름

판매자 상품 등록 → AI 특성 추출 → 익명 상품 공개 → 구매자 취향 선택 → 블라인드 예약 → 실물 공개 및 구매 확정

### AI 기능

- 이미지 속성 인식
- 개인 취향 매칭
- 상품 설명 생성

### 핵심 기술

- 블라인드 정보 접근 제어
- 실시간 예약
- 거래 상태 머신
