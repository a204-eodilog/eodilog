# 어디로그 화면 목록

> 사용자 흐름(`docs/flow/user-flow.md`)을 화면 단위로 나눈 목록이다. 와이어프레임·디자인·FE 업무 배정의 기준으로 쓴다.

**표기 규칙**

- 화면 ID는 `S01`~`S50`. 이어행 번호와 무관하게 새로 매긴다.
- **흐름**은 `user-flow.md`의 장 번호다.
- **순서**는 개발 순서 제안이다. `핵심` = 시연 한 바퀴(모으기 → 추천 → 투표 → 코스 → 사진 → 피드 → 저장), `완성도` = 그다음, `확장` = 팀 확인 후.
- **FE**는 담당 제안이다. A = 박세은(진입·홈·마이페이지·친구·알림), B = 윤영광(저장·추출·사진·평가·경비), C = 정인경(여행·추천·투표·코스·여행 중·채팅). 팀 확인 후 바꾼다.
- `Q-N`은 PRD 미정 결정, `[F-N]`은 흐름 문서의 제안. 해당 화면의 세부는 결정 후 확정한다.
- **주요 상태**는 PRD 검증 조건에 있는 것만 적었다. 모든 목록·상세 화면은 공통으로 로딩 / 실패(재시도) / 빈 상태 / 권한 없음을 가진다(§9).

## 0. 탭 구조 [F-1]

| 탭 | 첫 화면 | 목적 |
| --- | --- | --- |
| 홈 | S05 | 친구 여행 지도, 트렌드, 좋아요 추천 |
| 여행 | S15 | 내 동행 그룹 목록 → 여행 상세(즐겨찾기·추천·투표·코스·여행 중·사진·평가·경비) |
| 저장 | S10 | 개인 즐겨찾기, 링크·캡처 등록 |
| 채팅 | S46 | 대화방 목록 |
| 마이페이지 | S37 | 내 피드 지도, 타임라인, 친구, 프로필·설정 |

- 하단 탭은 각 탭의 첫 화면에만 보인다. 상세·입력·편집 화면은 탭을 숨기고 ← 뒤로를 둔다.
- 알림 목록(S49)은 홈 상단 아이콘에서 연다 [F-7]. 알림 팝업(S48)은 앱 실행·복귀 시 어느 탭에서든 뜬다.
- 여행 상세(S17)는 허브 화면이다. 그 안의 섹션은 탭이나 세로 섹션 중 와이어프레임에서 정한다.
