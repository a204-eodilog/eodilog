# 어디로그 화면 목록

> 현재 Figma Page0에 있는 화면과 상태를 [사용자 흐름](./user-flow.md) 기준으로 정리한 목록이다. 와이어프레임·디자인·FE 업무 배정의 기준으로 쓴다.

**표기 규칙**

- 화면 ID는 `S00`~`S50`, 막힘 해소로 추가한 화면은 `N3`·`N4`·`N7`·`N8`·`N9`, 말로 경비 입력으로 추가한 화면은 `N10`·`N11`이다(2026-11-12, Figma "10-1. 여행 후 · 말로 경비 입력" 구역). 지운 화면 ID(N1·N2·N5·N6)는 다시 쓰지 않는다.
- **흐름**은 `user-flow.md`의 장 번호다.
- **Figma 상태**는 Page0 기능 섹션(1~13번)에 그려진 아트보드다. 오류 상태는 15번 섹션에 따로 있다. `(파랑)`은 아직 Page0에는 없고 "어디로그(파랑)" 페이지에만 그린 상태다.
- **순서**는 개발 순서 제안이다. `핵심` = 시연 한 바퀴, `완성도` = 그다음, `확장` = 팀 확인 후.
- **FE**는 담당이다(2026-11-03 확정). 프론트에서 만들기 어려운 기술 하나씩을 맡도록 나눴다. A = 정인경(지도: 진입·홈·장소 검색·편의시설·마이페이지·친구), B = 박세은(업로드·AI·배포: 저장·추출·사진·평가·경비·내 기록·확인창), C = 윤영광(실시간: 여행·추천·투표·코스·여행 중·채팅·알림). 같이 쓰는 부품은 [10. 요약](#10-요약) 아래 표를 따른다.
- `(v0.4)`는 PRD 확정, `(결정)`은 2026-10-27 결정, ⚠️는 PRD v0.4와 달라 팀 합의가 필요한 부분이다.
- 여행에 함께하는 사람은 **동행**이라고 부른다. 화면 문구와 문서 모두 같은 말을 쓴다.
- 모든 목록·상세 화면은 공통으로 로딩 / 실패(재시도) / 빈 상태 / 권한 없음을 가진다.

## 0. 탭 구조

| 탭 | 첫 화면 | 목적 |
| --- | --- | --- |
| 홈 | S05 | 친구 여행 지도, 트렌드, 좋아요 추천, 알림 아이콘 |
| 여행 | S15 | 참여 중인 여행 목록 → 여행 상세(S17) |
| 저장 | S10 | 개인 즐겨찾기, 링크·캡처 등록 |
| 채팅 | S46 | 여행 그룹 대화방 목록 (1:1 없음 ⚠️) |
| 마이페이지 | S37 | 내 피드 지도, 내 여행 목록, 타임라인, 친구, 프로필·설정 |

- 하단 탭은 각 탭의 첫 화면에만 보인다. 상세·입력 화면은 탭을 숨기고 ← 뒤로를 둔다.
- 알림 목록(S49)은 홈 상단 아이콘에서 연다. 알림 팝업(S48)은 앱 실행·복귀 시 어느 탭에서든 뜬다.
- 여행 상세(S17)는 허브 화면이다. 섹션 배치는 아이콘 격자 / 탭 두 안이 Figma에 있다.
