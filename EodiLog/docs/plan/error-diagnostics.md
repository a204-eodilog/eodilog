# 오류 진단 (EODI-131)

공통 예외 처리기와 인증 필터가 traceId·코드·diagnostics를 기록한다. diagnostics에는 예외 타입과 클래스.메서드:줄번호만 담는다. 예외 메시지·Throwable 원문·파일명·suppressed 정보는 출력하지 않는다. 기존 API 응답 계약은 유지한다.

예외당 최대 8프레임을 첫 애플리케이션 프레임까지 기록한다. 앱 프레임이 8개 밖이면 생략된다. cause는 최상위 포함 최대 4개이며 identity 기반 순환 참조 감지로 중단한다. 빈 스택은 unknown이다.

프레임·cause 상한, 순환 참조 종료와 메시지 비노출은 단위 테스트로, 공통 handler와 인증 필터 오류 응답·로그는 기존 통합 테스트로 검증한다. 전체 스택이 필요하다는 이유로 운영에서 예외 원문을 로그에 넘기지 않는다.
